# Code of Conduct

Vibe to Code is a learning community. We welcome people of every background and experience level.

## Our standard

Be patient, specific, and respectful. Give feedback about the work, not the person. Make room for beginner questions, acknowledge mistakes openly, and help others learn without embarrassment.

Harassment, discrimination, personal attacks, deliberate intimidation, sexualized conduct, doxxing, and sustained disruption are not acceptable in any project space.

## Enforcement

Project maintainers may edit or remove contributions and restrict participation when behavior harms the community. Serious or repeated problems can be reported privately to the project owner through the contact method listed on the owner's GitHub profile.

Reports will be reviewed as promptly and privately as practical. Anyone handling a report must avoid conflicts of interest and protect the reporter's privacy.
