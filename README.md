## Why Vibe to Code exists

AI can create an app in minutes, but that does not automatically teach you what the code does.
Vibe to Code closes that gap without making beginners feel lost or embarrassed.

Every lesson is designed to help you:

1. **Understand** one idea in plain language.
2. **Predict** what a small piece of code will do.
3. **Run** a working example and observe the output.
4. **Debug** a realistic mistake instead of fearing errors.
5. **Build** something useful with the concept.

No unexplained jargon. No giant theory dump. No pretending that AI output is automatically correct.

## Our lesson standard

Every published lesson should be:

- clear to someone seeing the topic for the first time;
- accurate enough to build on later;
- readable on phones and usable with a keyboard;
- based on small, working, testable examples;
- honest about security, privacy, and production risks;
- reviewed before being marked complete.

<details>
<summary><strong>Run Vibe to Code on your computer</strong></summary>

### What you need

- [Node.js](https://nodejs.org/) 20.9 or newer
- [Git](https://git-scm.com/)
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)

### Setup

```bash
git clone https://github.com/medddhir/vibe-to-code.git
cd vibe-to-code
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Check your work

```bash
npm run check
```

That command checks TypeScript, runs the linter, and creates a production build.

</details>
